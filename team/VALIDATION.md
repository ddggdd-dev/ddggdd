# 검증 결과

2026-11-14, Node 22.23 환경 (운영 이미지는 Node 24).

- TypeScript 검사 통과
- Vite 운영 빌드 통과
- 자동시험 14개 통과 / 실패 0 (`npm test`)
- 휴대폰 크기(390×844) 헤드리스 브라우저로 팀 보드, 날짜 시트, 모임 만들기, 모임 확인, 초대 참여, 팀원 화면을 확인. 콘솔 오류 없음.

자동시험 범위:
1. 아무것도 안 적은 팀원은 "가능"이 아니라 "미입력"
2. 저녁 시간대 판정: 점심만 안 되는 날은 저녁 가능
3. 시간 미정일 때 일부 시간만 안 되는 날은 참고 표시
4. 좋아요는 시간대 전체를 덮을 때만 반영, 추천 순위, 주말·오늘 제외
5. 팀 만들기·초대 참여, 다른 팀 열쇠로 접근 차단, 잘못된 초대 링크 거절
6. 날짜 표시·지우기, 지난 날짜·잘못된 시간 거절, 마지막 수정 시각 갱신
7. 팀장 전용 기능, 내보낸 팀원 접근 차단, 초대 링크 재발급 시 예전 링크 차단
8. "어려워요"가 보드에 반영되고 "참석"으로 바꾸면 되돌아감, 확정 후 응답 잠김
9. 기존 하루 종일 표시는 유지, 모임 삭제 시 그 모임이 만든 표시만 삭제
10. 이름 숨기기: 일반 팀원에게 "어려워요" 이름 숨김, 팀장에게는 보임
11. 재시작 후 데이터 유지, 보관 기간 정리
12. 캘린더 파일·구글 링크의 한국 시간 변환과 특수문자 처리
13. HTTP: 다른 출처 쓰기 거절, 쿠키 속성, 보드 집계, 서버 소스 노출 차단
14. HTTP: 개인 링크로 다른 기기 이어 쓰기, 공유 미리보기 HTML 이스케이프, 카카오 키 있을 때만 CSP 허용

확인하지 못한 것 (실제 환경 필요):
- 실제 VPS Docker 빌드, 네트워크, nginx 반영

- 카카오 JavaScript 키를 넣었을 때 공유 버튼 동작
