# 되는날 · 우리 팀 되는 날 보드 (1단계)

`ddggdd.tech/team/`에서 동작하는 팀 모임 날짜 앱입니다. 투표를 만들지 않고, 팀원이 평소에 적어 둔 "안 되는 날"로 모임 날짜를 바로 고릅니다.
기존 Hostinger VPS의 Docker·nginx에서 동작하고, 외부 데이터베이스나 로그인 서비스는 쓰지 않습니다.

## 사용 흐름

1. **팀 만들기** (`/team/`): 팀 이름과 내 이름만 입력. 가입·로그인 없음.
2. **초대**: 초대 링크(`/team/j/<초대값>`)를 단톡방에 공유. 받은 사람은 이름만 넣고 참여.
3. **안 되는 날 적기**: 보드에서 "수정"을 누르고 날짜를 탭하면 하루 종일 안 됨. 날짜를 눌러 "저녁만 안 돼요", "좋아요 ♥"도 가능.
   바뀐 게 없으면 "바뀐 것 없어요"로 기록을 최신으로 표시.
4. **보드 보기**: 시간대(저녁·점심·하루 종일·시간 미정)별로 날짜마다 "되는 인원/전체"가 진하기로 보이고, 평일 추천 3개가 위에 나옴 (주말 포함 선택 가능).
   아무것도 안 적은 사람은 "가능"으로 치지 않고 "미입력"으로 셉니다.
5. **이날로 하자**: 날짜를 골라 모임을 만들면 공유 카드가 생김. 팀원은 "참석 / 어려워요"만 누름. "어려워요"는 보드에도 반영.
6. **확정·캘린더**: 만든 사람이나 팀장이 확정. 각자 아이폰·삼성 캘린더(.ics) 또는 구글 캘린더 링크로 추가.

배려 설정: 팀장이 "안 되는 사람 이름 숨기기"를 켜면 팀원에게는 숫자만 보입니다. 불가 사유는 묻지 않습니다.
다른 폰에서 이어 쓰기: 팀원 화면의 "개인 링크"(`/team/m/<열쇠>`)를 본인 다른 기기에서 열면 됩니다.

## 구조

```
브라우저(카톡 안) → ddggdd.tech/team/ → 기존 nginx web → ddongko-team (Node 24) → /data/team.sqlite
```

| 파일 | 역할 |
| --- | --- |
| `src/board.mjs` | 보드 계산 (서버·화면 공용): 시간대 판정, 날짜별 집계, 추천 순위 |
| `store.mjs` | SQLite 저장, 권한 검사 |
| `server.mjs` | HTTP, 공유 미리보기(OG 태그), 캘린더 파일, 보안 헤더 |
| `src/App.tsx` | 휴대폰 화면 |
| `admin.mjs` | `backup`, `stats` (개인정보 없는 숫자만) |
| `deploy/` | Docker compose, nginx 위치 설정, 환경변수 예시 |

### 데이터

- 팀, 팀원(이름, 역할, 해시된 기기 열쇠, 마지막 수정 시각), 날짜 표시(안 됨·좋아요와 시간), 모임, 참석 응답.
- 저장하지 않는 것: 불가 사유, 캘린더 내용, 전화번호·이메일, 카카오·구글 계정.
- 보관: 지난 날짜의 표시는 90일 뒤 삭제, 180일 동안 아무도 쓰지 않은 팀은 삭제 (서버가 1시간마다 정리).
- 다음 단계용 빈 칸: `teams.chat_hash`(카톡 공유 웹훅), `members.kakao_id`(카카오 로그인).

### 보안

- 기기마다 팀별 HttpOnly 쿠키(`dn_<팀ID>`). 서버에는 열쇠의 해시만 저장.
- 초대 링크와 모임 주소는 추측할 수 없는 긴 값. 팀장이 초대 링크를 새로 만들면 예전 링크는 막힘.
- 모든 쓰기 요청은 Origin, JSON, `X-Team-Request` 헤더를 검사. 요청 횟수 제한.
- CSP는 자기 도메인만 허용. `KAKAO_JS_KEY`가 있을 때만 카카오 SDK 주소를 추가로 허용.
- nginx 설정의 `access_log off`를 유지하세요. 개인 링크 주소에 열쇠가 들어 있습니다.

## 카카오톡 공유 버튼 (선택)

`KAKAO_JS_KEY`가 비어 있으면 휴대폰 공유창이나 링크 복사로 동작합니다.
카카오 공유 버튼을 쓰려면 카카오디벨로퍼스에서 앱을 만들고, JavaScript SDK 도메인에 `https://ddggdd.tech`를 등록한 뒤 JavaScript 키를 `team.env`에 넣으세요.
같은 앱이 2단계(톡캘린더 연동)에도 쓰이므로 톡캘린더 사용 권한 신청도 미리 해 두면 좋습니다.

## 검사 (Node 24)

```sh
npm ci
npm run typecheck
npm run build
npm test
```

로컬 미리보기: `npm run build && npm run dev` → http://127.0.0.1:4173/team/

백업: `docker exec ddongko-team node admin.mjs backup` → `/data/backups/`. 같은 디스크이므로 다른 곳에 복사하세요.
`docker compose down -v`는 데이터를 지우므로 쓰지 않습니다.
