01관리자님 고민 네 가지

통화에서 하신 말씀을 짧게 옮겼습니다.

1
외국 손님이 미리 볼 정보가 없다"외국인들도 가격이랑 얼마나 나오는지 정확하게 알고 가고 싶을 텐데, 나와 있는 정보가 별로 없더라고요."
2
캐치테이블에 걸린 사이트가 낡았다"7~8년 전에 만든 네이버 블로그라 운영도 잘 안 되고 볼 정보도 별로 없고요." 마음에 들게 되면 새 홈페이지를 캐치테이블·Google에 걸고 싶다.
3
그램·영업시간·주차 정보를 고쳐야 한다네이버·Google 비즈니스 프로필 계정을 받아 내일·모레쯤 고치시기로 함. 이미 고치셨으면 바뀐 값만 알려 주세요.
4
부위마다 맛있게 먹는 법을 '흑돼지 오마카세처럼' 알리고 싶다"흑돼지 오마카세처럼 코스별로 부위를 맛있게 먹는 방법들을 소개하는 일." 코스를 정리해 보내 주시기로 함.

그리고 "요즘은 한국인 손님보다 외국인이 많이 오신다(중국인이 가장 많고 영어권도 꽤 많다)"고 하셨습니다. 그래서 먼저 이미 오는 외국 손님이 미리 알고 오게 하고, 그다음 외국 손님이 쓰는 앱에 더 잘 보이게 하는 순서로 짰습니다. 짐작

03고민별 해결책

이미 해 둔 것과 남은 것, 누가 할 일인지 나눴습니다.

1외국 손님이 미리 볼 정보 → 홈페이지
해 둔 것
  • 한국어·영어·중국어로 화면 전체가 바뀌는 홈페이지 미리보기
  • 메뉴 21개와 가격(캐치테이블 8월 31일 기준), 고기류·식사류로 나눔. 일부 메뉴는 그램 확인 중
  • 지도·주소 복사·전화, 외국 손님용 캐치테이블 글로벌 링크(이 페이지는 지금 전화 예약 안내만 있고 번호가 010-8004-8985라, 번호 정답이 정해지면 맞춥니다)
  • "직원에게 보여 주세요" 한국어 문장 카드(외국어 화면에서)
남은 것
  • 그램·가격·영업시간 확인 → 관리자님
  • 영어·중국어 원어민 확인 → 저희(방법 알아보는 중)
  • 정식 주소 정하기(지금 미리보기 주소로 쓸지, 천돈가 이름의 주소를 쓸지. 이름 주소는 비용이 들며 따로 말씀드리겠습니다) → 관리자님 결정
2낡은 블로그 → 새 홈페이지로 바꿔 걸기
할 일
  • 캐치테이블·Google·네이버의 '홈페이지' 칸에 새 주소 넣기 → 관리자님(바꿀 위치는 저희가 화면으로 찾아 안내)
  • 검색 등록(Google·네이버) 방법은 오픈 때 함께 정하겠습니다
3앱마다 다른 정보 → 한 장으로 맞추기
할 일
  • 앱별 지금 값과 고칠 곳을 표 한 장으로 → 저희
  • 정답 정하기(손님이 걸 번호 하나, 시간, 주차) → 관리자님
  • 네이버·Google에서 고치기 → 관리자님(이미 하시기로 함) · 홈페이지 반영, 씨트립 수정 요청(방법 확인 중) → 저희
4흑돼지 오마카세 → 먹는 법을 보여 주기
해 둔 것
  • 홈페이지 첫 화면 한 줄 "흑돼지 오마카세처럼, 부위마다 순서대로 구워 드려요"
  • '먹는 순서 4단계' 자리(지금은 손님 후기와 캐치테이블 소식으로 정리한 임시 내용)
남은 것
  • 실제 코스 순서·부위별 먹는 법 보내 주기 → 관리자님
  • 받으면 홈페이지·외국어 화면·테이블용 '먹는 법 카드'에 같은 내용으로 → 저희
