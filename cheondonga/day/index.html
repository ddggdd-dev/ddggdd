09AI에게 이렇게 물으면 더 좋습니다

이번 질문 순서가 좋았던 점과, 더 물었으면 좋았을 것.

좋았던 점

  • 두 번째 말에서 목표를 한 줄로 정함 ("낮 시간 채우기")
  • 여러 안 → 계산 → "잘될지" 반대로 묻기 → 다른 안 → 깊게
  • 마지막에 "과장하지 말고", "검토 과정 포함"을 요구

더 물었으면 좋았을 것

  • "우리 실제 숫자를 줄 테니 다시 계산해": 재료비·낮 팀 수를 주면 짐작이 계산이 됩니다.
  • "이 안이 실패한다면 이유가 뭘까?"를 처음부터
  • "확인한 것과 짐작을 나눠, 출처 링크를 달아"를 처음부터
  • "가장 싸고 빠르게 시험해 볼 방법은?"
  • "다른 AI에게 검토받아": 같은 AI는 자기 답에 너그럽습니다.
  • "누가 읽을지"를 마지막이 아니라 처음에: 처음부터 "유건이에게 보낼 거야"라고 하면 분석 단계부터 표현과 깊이가 맞춰집니다.
